ZIP 하나로 방을 만들고 바로 들어가요. 에픽 계정도, 따로 설치할 프로그램도 필요 없어요.

Windows용 ZIP 받기

최신 버전을 확인하는 중이에요…

시작하는 법

  1. ZIP 전체를 한 폴더에 풀어요. 압축 파일 안에서 바로 실행하지 마세요.
  2. BasicFPS-DX11.exe → 방 만들기 → 닉네임을 넣으면 방이 열리고 바로 들어가요.
  3. 방은 방 목록에 자동으로 올라가요. 친구는 게임의 방 목록에서 골라 들어오면 돼요. 내 PC가 그대로 서버예요.

지금 열린 방

  • 방 목록을 불러오는 중이에요…

15초마다 새로 고쳐요. 게임을 끄거나 방을 닫으면 목록에서 사라져요.

조작

WASD 이동 · Shift 걷기 · 클릭 사격 · R 재장전 · Tab 점수판 · Esc 메뉴

알아 두세요

서명되지 않은 개인용 빌드라 Windows가 경고를 보여 줄 수 있어요. 처음 방을 만들 때 Windows 방화벽이 물으면 허용을 눌러야 친구가 들어올 수 있어요. 방을 열면 게임이 공유기 포트(UPnP)를 자동으로 열어 보고, 목록에 인터넷 접속 가능 또는 같은 공유기만으로 표시해요. 같은 공유기만으로 나오면 공유기 설정에서 UPnP를 켜거나 방 포트(보통 3000, TCP)를 내 PC로 포트포워딩해 주세요.

기존 런처를 쓰던 분은 런처 설치 파일도 받을 수 있어요.
