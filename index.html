언리얼 Windows 시험판

설치 상태를 확인하고 있어요… Windows 빌드 성공 전에는 다운로드할 시험판이 없어요. 기존 게임은 계속 사용할 수 있어요.
방을 외부에 열려면 방을 연 PC의 방화벽과 TCP 3000 포트 설정이 필요해요.
언리얼 시험판은 별도 게임 실행 파일을 사용해요. 최초 실행에는 Windows 필수 구성 요소 설치가 필요할 수 있어요.
