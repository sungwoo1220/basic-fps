# Basic FPS: DX11 Windows 시험판

에픽 계정과 언리얼 없이 실행하는 별도 Windows 10/11 x64 시험판이에요. **이 ZIP 하나로 방을 만들고 바로 플레이할 수 있어요.** 기존 런처나 Node.js 설치가 필요 없어요. 기존 런처와 브라우저 게임은 덮어쓰거나 업데이트하지 않아요.

## 실행

1. 저장소 [Releases](https://github.com/sungwoo1220/basic-fps/releases)에서 **Basic FPS DX11 Windows 시험판**의 `BasicFPS-DX11-Win64.zip`을 받아요. 태그는 `dx11-test-`로 시작해요. 서명되지 않은 개인용 빌드이므로 이 저장소에서 받은 파일인지 확인하세요.
2. ZIP **전체**를 한 폴더에 풀어요. `BasicFPS-DX11.exe` 옆의 `room` 폴더가 방 서버예요. 압축 파일 안에서 바로 실행하지 마세요.
3. `BasicFPS-DX11.exe` → **방 만들기** → 닉네임 → **방 만들기**. 방이 열리면 자동으로 들어가고 연습 봇 3명이 있어요. 처음 실행할 때 Windows 방화벽이 Node.js를 물어보면, 친구와 같은 공유기에서 함께할 때만 허용하세요. 혼자 하면 허용하지 않아도 돼요.
4. 친구는 메뉴에 표시된 **친구 접속 주소**를 **다른 방에 연결**에 입력해요. 기존 런처나 브라우저 게임으로도 같은 주소에 들어올 수 있어요.
5. **내 방 닫기** 또는 앱 종료를 누르면 방도 함께 닫혀요. 3000번을 이미 다른 방이 쓰고 있으면 빈 번호로 열려요.
6. WASD 이동, 마우스 시점, Shift 걷기, 왼쪽 클릭 사격, R 재장전, Tab 점수판, Esc 메뉴를 써요. **마우스 감도**는 메뉴의 −/+(0.01씩)로 바꾸거나 숫자를 눌러 직접 입력해요. 브라우저 게임과 같은 값(기본 0.350)을 쓰고 이 PC에 저장돼요. **연습 봇**은 내가 만든 방에서만 켜고 끌 수 있어요(켜면 3명). 피해·탄약·전적은 방 서버가 판정해요.

## 노트북에서 확인할 것

- 메뉴의 GPU 이름을 확인해요. 외장 GPU를 쓰려면 Windows 그래픽 설정에 런처가 아닌 **`BasicFPS-DX11.exe`**를 추가해요.
- **화면 모드**를 누르면 창모드 → 전체화면 창모드 → 독점 전체화면을 순서대로 바꿔요. 화면이 정상일 때만 **유지**를 누르세요. 15초 안에 선택하지 않거나 전환 중 포커스를 잃으면 이전 모드로 돌아가요. 독점 전체화면은 DXGI가 실제로 독점 상태를 보고할 때만 `DXGI 확인`이 표시돼요. 독점이 풀리면 안전하게 창모드·메뉴로 돌아가요. 재실행하면 창모드에서 시작해요.
- **MSAA**는 끔/2배/4배이며 GPU가 지원하지 않는 단계는 건너뛰어요. DX11 포워드 렌더링과 실제 창 해상도를 사용하며 렌더 배율 조절, FXAA, TAA는 없어요. 같은 위치에서 각 MSAA 단계로 바꾼 뒤 **플레이 중** FPS를 비교하세요. 메뉴는 30FPS 제한이라 비교에 쓰지 않아요.
- **이방성 필터링**은 끔/2배/4배/8배/16배이고 기본 16배예요. 바닥·벽·상자의 격자 질감이 비스듬히 보일 때 멀리까지 또렷해져요. 외장 GPU에서는 보통 성능 차이가 거의 없어요. 재실행하면 16배로 돌아가요.
- FPS 제한은 60/144/240/300/무제한 중에서 선택해요. 프레임 수는 앱이 제출한 프레임 기준으로, 모니터에 실제 표시된 장수나 외장 GPU/MUX 전환을 뜻하지 않아요. 이 시험판은 그래픽 방식과 기존 방 호환을 검증하기 위한 것으로, 기존 게임의 모든 화면이나 설정을 복제하지 않아요.

## 직접 빌드 (선택)

Visual Studio 정식판에서 **C++를 사용한 데스크톱 개발**, Windows SDK, CMake 도구를 설치한 Windows x64에서 실행해요. 빌드에 Epic·언리얼·특정 언리얼용 컴파일러 버전·GitHub runner 연결은 필요 없어요. 기본 CMake가 설치된 Visual Studio를 찾게 두면 돼요. 직접 빌드한 실행 파일로 방을 만들려면 실행 파일 옆에 `room` 폴더(node.exe, server.js, public, node_modules/ws)가 있어야 해요. 자동 검사의 조립 단계를 참고하세요.

```powershell
cmake -S dx11 -B dx11/build -A x64
cmake --build dx11/build --config Release --parallel
ctest --test-dir dx11/build -C Release --output-on-failure
.\dx11\build\Release\BasicFPS-DX11.exe
```

GitHub 자동 검사에서 ZIP에 들어가는 폴더 그대로, Node.js가 없는 환경에서 앱이 **직접 연 방**과 별도 방에 입장·이동·사격·재장전하는 것을 확인하고, 소프트웨어 DX11로 MSAA 끔/2배/4배의 화면을 그려 검사해요. **노트북의 실제 GPU, 독점 전환·복구, 체감 FPS, MUX는 이 검사만으로 확인되지 않아요.**
